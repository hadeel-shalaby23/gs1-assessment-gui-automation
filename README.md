# **GS1 GUI Test Automation Assessment**
## Overview

**This project is implemented using:**
- Java
- Selenium Webdriver 
- Testng
- Maven
- Intellij IDEA
- Google Chrome

The project contains two automated test scenarios using the website:

https://the-internet.herokuapp.com/

## **Test Scenarios**

1- File Upload
2- Dynamic Loading

## **Test Execution**

Run the file testng.xml 

OR

Run using Maven from root using command:
run mvn 

## **Requirements**
- Java JDK
- Intellij IDEA
- Maven
- Google Chrome

Selenium WebDriver and TestNG dependencies are managed through Maven.

ChromeDriver is automatically managed by Selenium Manager.
